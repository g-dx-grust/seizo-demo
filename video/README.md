# 工場コックピット デモ動画（Remotion）

[DEMO_SCRIPT.md](../DEMO_SCRIPT.md) の8ステップ順路に沿ったデモ動画を自動生成するプロジェクトです。

- 成果物: `out/demo.mp4`（1920x1080 / 30fps / H.264 / 無音・字幕入り）
- 構成: オープニング → ①〜⑧（各章: チャプターカード → 操作録画＋字幕＋ハイライト/軽ズーム） → エンディング

## 仕組み

```
record.mjs   Playwright(Chromium)がアプリを台本どおり自動操作し clips/chN.webm に録画。
             同時に字幕(cue)・ズーム(zoom)・クリックのタイムラインを clips/meta.json に記録
prepare.mjs  webm → public/chN.mp4（30fps CFR・H.264）に変換し、
             タイムラインを実測動画長で補正して src/generated/demoData.json を出力
src/         Remotion 合成（オープニング/チャプターカード/字幕/ハイライト枠+軽ズーム/エンディング）
```

- 字幕・ズームの内容とタイミングは **record.mjs 内の各章シナリオ（ch1〜ch8）** が唯一のソースです。
  文言を変えたい場合は record.mjs の `cue(...)` を編集 → その章だけ撮り直し。
- チャプターカードの見出し・課題番号pillは `src/chapters.ts`。
- エンディングの提供元社名は `src/chapters.ts` の `VENDOR_NAME`（空なら非表示）。

## 再レンダリング手順

```bash
# 0) アプリを起動しておく（別ターミナル、http://localhost:5173）
cd .. && npm run dev

# 1) 録画（全章 約6分。章を指定して撮り直しも可）
cd video
npm run record          # 全8章
node record.mjs 5,7     # 指定章のみ再録画（他の章のmeta/映像は維持）

# 2) 変換＋タイムライン生成（再録画した章だけmp4変換し直します）
npm run prepare-data

# 3) レンダリング
npm run render          # → out/demo.mp4
```

プレビューしながら調整する場合は `npm run studio`（Remotion Studio が開きます）。

## 各章とアプリ連動の前提

| 章 | 内容 | state前提（record.mjsが自動処理） |
|---|---|---|
| ① | 経営サマリー → アラートから設備へ | 初期状態 |
| ② | 設備稼働（赤カード・24hタイムライン・停止コスト） | 初期状態 |
| ③ | 生産計画・実績（未連携の赤バナー＝⑦への伏線） | 初期状態 |
| ④ | 案件別採算 → K-1088詳細 → PO-2660承認待ち | 初期状態（13.4%表示） |
| ⑤ | モバイル承認 → 13.4%→12.1% 反映（山場①） | 1コンテキスト内でSPA遷移を維持 |
| ⑥ | カンバン → ガント | 冒頭で高速承認（映像はトリム済み） |
| ⑦ | CSV取込ウィザード → 緑バナー（山場②） | 同上 |
| ⑧ | 通知センター → ナレッジ | 冒頭で高速承認＋CSV取込（トリム済み） |

※ アプリのstateはメモリのみのため、各章は必ずSPA内クリックで遷移し続けるように書かれています。
録画スクリプトを編集する際も **章の途中で page.goto しない** こと（承認・取込stateが消えます）。

## 注意

- フォントはGoogle Fonts（Noto Sans JP）。録画・レンダリングともにネット接続が必要です。
- Remotion は会社規模によって有償ライセンスが必要な場合があります（従業員4名以上の企業等は Company License）。
  商用利用の前に https://remotion.dev/license を確認してください。
- 録画時に疑似カーソル・クリックリップルをCSS注入で描画し、右下の「デモをリセット」ボタンは非表示にしています。
